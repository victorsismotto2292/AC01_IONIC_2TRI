# ENUNCIADO EXERCÍCIO
Um empreendedor do ramo agrícola frequentemente decide quais culturas plantar em
diferentes áreas do país com base na temperatura média dos últimos 4 meses. Desenvolva
um aplicativo que permita a inserção das médias de temperatura dos últimos 4 meses e,
com base nesses dados, sugira qual cultura é mais adequada para o plantio.

Por exemplo:

- **Morangos** -> Temperatura ideal entre 15°C e 25°C. Os morangos crescem melhor em
climas temperados, preferindo temperaturas mais amenas, porém não
excessivamente frias.

- **Uvas** -> Tolerantes a uma ampla faixa de temperatura, mas preferem climas mais
quentes, com temperatura ideal entre 20°C e 30°C. Podem também se desenvolver
em regiões mais frescas, desde que a estação de crescimento seja suficientemente
longa.

- **Laranjas** -> Frutas tropicais a subtropicais que preferem temperaturas mais elevadas.
A faixa ideal de temperatura para o cultivo de laranjas está entre 15°C e 30°C. Elas
necessitam de uma estação de crescimento longa e quente para amadurecer
completamente.
#
O aplicativo deve apresentar uma lista das culturas ideais para a temperatura média
inserida em uma nova tela.

Amplie a lista para incluir pelo menos 10 culturas diferentes. Pesquise por culturas que se
adaptem a temperaturas extremamente baixas ou altas. Não é necessário fornecer detalhes
sobre cada cultura, apenas apresentar uma lista do que pode ser plantado.

Utilize o **ion-range** para selecionar as 4 temperaturas desejadas.
