# ENUNCIADO EXERCÍCIO
-
Um empreendedor do ramo agrícola frequentemente decide quais culturas plantar em
diferentes áreas do país com base na temperatura média dos últimos 4 meses. Desenvolva
um aplicativo que permita a inserção das médias de temperatura dos últimos 4 meses e,
com base nesses dados, sugira qual cultura é mais adequada para o plantio.
